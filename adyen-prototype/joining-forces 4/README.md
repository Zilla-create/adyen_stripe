# Adyen — Enterprise reality, version 3

Complete static prototype with the approved October 1, 2026 preset, all fonts and graphics, motion controls, and text/size editor. No build step or dependencies required.

## Add to GitHub

1. Unzip this archive.
2. Upload its contents to your repository root, or to a subfolder in your existing GitHub Pages site. Keep index.html, style.css, scene.js, tuning.js, and assets together.
3. For a new GitHub Pages site, enable Pages for the branch and folder containing these files in your repository settings.

Upload the extracted files, not the ZIP itself. All asset paths are relative so the prototype works in a subfolder.

## Preview and controls

Open index.html in a browser, or serve the folder with a static server.
Append ?tune=1 to open the controls, or use the on-page controls button.
Append #continuation to jump to the enterprise scene.
Changes in the controls are saved in the current browser; Reset restores the included approved preset. Copy settings exports your changes as JSON.

The preset is included in presets/2026-10-01-approved.json. Its 40.1% position is a review snapshot, not a forced starting position.
