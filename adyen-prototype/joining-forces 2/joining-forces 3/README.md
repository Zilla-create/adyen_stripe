# Adyen — Joining Forces prototype

Standalone prototype for the Adyen Joining Forces campaign concept.

Open `index.html` in a browser, or serve this folder with any static web server.

The prototype includes:

- Adyen UI and Mono fonts
- Official Adyen logo asset supplied for the prototype
- Dark dotted-grid environment
- Two depth-based particle streams
- Cursor parallax and scroll-driven camera movement
- Start, one-scroll and two-scroll compositions

The previous prototype is not included in this package. Keep its existing folder when uploading this version.

The final transition separates the text exit, immersive central perspective, and label convergence. Further scrolling carries the camera forward through the shared stream.
